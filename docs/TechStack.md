Guest Mobile Interface & Main Display(Web Frontend),Thymeleaf + HTMX + Alpine.js,Requirement: Must be accessible via mobile browser instantly upon QR scan. Must render elder-friendly UI without downloading heavy JS bundles.,"Next.js (React), Vue.js, Angular.","Sends pure, pre-rendered HTML from the server, resulting in lightning-fast initial load times. Alpine.js provides instant local feedback (e.g., loading spinners) without waiting on the server. Keeps the entire project in a single Spring Boot codebase.","Complex client-side features (like the host's drag-and-drop media dashboard) require sprinkling in vanilla JS libraries (like Dropzone.js), as HTMX is not designed for heavy client-side logic."
Real-Time Game Synchronization(Host Control & Player States),Spring WebSockets (STOMP) with a Redis broker,"Requirement: The host's ""Next"" button must instantly update the main display and up to 200 guest mobile phones in the room without page refreshes.","Server-Sent Events (SSE), Firebase Realtime Database.","Spring WebSockets with STOMP (Simple Text Oriented Messaging Protocol) provides a robust, native publish-subscribe model. Using Redis as a message broker allows the WebSocket connections to scale seamlessly across multiple Spring Boot server instances if multiple events are happening concurrently.",STOMP adds slight protocol overhead compared to raw WebSockets. Managing a Redis instance adds to the infrastructure complexity.
Media Processing & Storage(Nostalgic Media Upload),Cloudinary (via Java SDK),"Requirement: Hosts must be able to drag-and-drop media, and the system must automatically crop and center them to fit elegant aesthetic templates.","AWS S3 natively, storing BLOBs in the database.","Cloudinary has a robust Java SDK. It processes media on the fly via URL parameters, automatically detecting faces to center crops and compressing images for spotty venue Wi-Fi, which solves the host's formatting pain point immediately.",Higher operational cost at scale compared to raw cloud storage; relies on a third-party API for core visual functionality.
Core Backend & API(Game Logic & Validation),Spring Boot (Java 17+),"Requirement: Needs to securely manage user accounts, handle complex relational data (templates, questions), and execute strict QA template business rules.","Node.js (Express), Python (Django), Go.","Spring Boot is highly structured, strongly typed, and excellent for complex enterprise-level business logic. The Spring ecosystem (Spring Security for host authentication, Spring Data JPA for database management) provides highly secure, battle-tested tools out of the box.","Higher memory footprint and slightly slower startup times compared to Node.js. Requires more boilerplate code, though Spring Boot significantly minimizes this compared to older Java EE frameworks."
"Primary Database(Users, Events, Question Banks)",PostgreSQL,Requirement: Needs to securely store deeply relational event data (Host -> Event -> Question Bank -> Individual Scores).,"MongoDB (NoSQL), MySQL.",PostgreSQL pairs flawlessly with Spring Data JPA/Hibernate. Its robust relational data integrity is crucial for accurately mapping nested data like pre-built event question banks and ensuring final leaderboard scores are tallied without anomalies.,"Schema changes require formal migrations (e.g., using Flyway or Liquibase), making it slightly less flexible for rapid prototyping than a NoSQL document database."
Audio Streaming(Ambient Soundscape),HTML5 Web Audio API & CDN,"Requirement: Must seamlessly loop elegant background music on the host's machine, capable of volume dipping during pauses.",Embedding third-party players (Spotify APIs).,"The Web Audio API runs entirely on the client (browser) side, allowing the frontend to automatically dip the volume when the ""Storyteller Pause"" WebSocket event is received, without touching the Java backend.","Browser auto-play policies are strict; the host must explicitly interact with the page (e.g., clicking ""Start Game"") before audio is permitted to play."
